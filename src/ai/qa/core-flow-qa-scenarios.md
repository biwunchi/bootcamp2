# 부트캠프 커뮤니티 핵심 플로우 QA 시나리오

## 1. 회원가입/로그인 플로우

### 1.1 회원가입 - 정상
- [ ] 필수 입력값(이메일, 비밀번호, 닉네임 등) 모두 입력 후 회원가입을 시도하면 정상적으로 성공해야 한다.
- [ ] 회원가입 성공 후 자동 혹은 수동 로그인 이어질 경우, 메인/홈 화면으로 이동하는지 확인한다.

### 1.2 회원가입 - 실패 케이스
- [ ] 이미 가입된 이메일로 시도시, "이미 존재하는 이메일" 에러 메시지가 나와야 한다.
- [ ] 비밀번호/이메일/닉네임 형식 불일치시, 입력 폼 아래에 적절한 에러 메시지가 표출되어야 한다.
- [ ] 필수값 미입력 시, 가입 버튼이 비활성화되거나 안내 메시지가 보여야 한다.

### 1.3 로그인
- [ ] 올바른 계정(이메일+비밀번호) 입력시 로그인 성공 및 메인 페이지 이동.
- [ ] 잘못된 비밀번호/이메일 조합일 경우, 에러 메시지가 노출됨.
- [ ] 로그아웃 버튼 클릭시, 즉시 세션이 해제되고 로그인 화면으로 이동한다.

---

## 2. 글 작성/수정/삭제 플로우

### 2.1 글 작성
- [ ] 로그인 후, 글쓰기 버튼 클릭시 글 작성 화면 진입됨.
- [ ] 제목·본문 등 필수 입력값 미입력 후 제출 시 오류 메시지가 노출됨.
- [ ] 모든 필수 입력값 입력시 글이 정상 등록되고, 등록 시 피드/리스트 최상단에 노출된다.

### 2.2 글 수정
- [ ] 본인 글에서 수정 버튼 클릭시, 기존 데이터가 입력된 수정 화면 진입됨.
- [ ] 내용 변경 후 저장하면 글이 정상적으로 업데이트되고, 리스트에 바로 반영된다.
- [ ] 타인의 글에선 수정 버튼이 보이지 않는다.

### 2.3 글 삭제
- [ ] 본인 글에서 삭제 버튼 클릭 시, 삭제 전 확인(모달 등) 절차가 있다.
- [ ] 삭제 후 해당 글이 피드/리스트에서 즉시 사라지고, 더 이상 접근 불가하다.
- [ ] 타인의 글은 삭제 버튼이 보이지 않는다.

---

## 3. 댓글/리플라이 작성 플로우

### 3.1 댓글 작성
- [ ] 로그인 후 게시글 상세 진입 → 댓글 입력 후 등록시, 댓글이 해당 게시글 하단에 즉시 나타난다.
- [ ] 미로그인 상태에선 댓글 입력창(또는 등록 버튼)이 비활성/숨겨져 있어야 한다.

### 3.2 댓글 삭제/수정
- [ ] 본인 댓글에 한해 수정/삭제 버튼이 노출된다.
- [ ] 댓글 수정 시 기존 내용이 입력된 폼에 진입하고, 수정 후 정상 저장된다.
- [ ] 댓글 삭제시, 삭제 전 확인 절차를 거친 후 즉시 리스트에서 사라진다.

### 3.3 리플라이(댓글의 답글) 작성
- [ ] 댓글 하단 리플라이 버튼 클릭시 해당 댓글에 대한 답글 입력 폼이 펼쳐진다.
- [ ] 답글 등록 시 해당 댓글 아래에 답글이 추가된다.

### 3.4 리플라이 삭제/수정
- [ ] 답글 또한 본인이 작성한 경우에만 수정/삭제 버튼이 노출된다.

---

## 4. 권한/유효성 및 예외 케이스
- [ ] 미로그인 사용자는 글·댓글·답글 작성이 제한(버튼 비활성/숨김 등)된다.
- [ ] 글/댓글/답글 수정/삭제는 본인만 할 수 있음(권한 확인). 
- [ ] 서버/API 오류 시 적절한 에러 메시지 및 사용자 행동 유도(UI 대응) 확인.

---

## 5. 기타(Edge/통합)
- [ ] 빠른 연타(버튼 다중 클릭) 시 중복 처리/등록/삭제가 방지되는지.
- [ ] 네트워크 지연/끊김 상황 발생시 로딩, 실패 안내 화면 노출되는지.
- [ ] 모바일 환경(반응형)에서도 주요 플로우에 문제 없는지.
- [ ] 본인 계정 삭제(탈퇴) 후, 로그아웃·재접속 불가 등 연속 플로우 동작 확인.
